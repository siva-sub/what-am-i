Derived from two reference plates actually inspected, not from taste.

## 1. WHAT THE PLATES TEACH

```text
   ┌────────────────────────────────────────────────────────────┐
   │ FROM PLATE A                                               │
   │                                                            │
   │ · Tone is made of LINES, not greys. The only inks are      │
   │   black and paper. Hatching spacing does all the work.     │
   │ · Cross-hatching = shadow. Single direction = midtone.     │
   │ · A one-ink print does not look cheap. It looks premium.   │
   │ · Thin ruled border, then a cream margin outside it.       │
   │   That margin is a plate-mark effect and it reads as       │
   │   quality even in a photocopy.                             │
   │ · Dense hatching survives being printed 2.5 in wide and    │
   │   reduced on a home printer. Photographs do not.           │
   └────────────────────────────────────────────────────────────┘

   ┌────────────────────────────────────────────────────────────┐
   │ FROM PLATE B                                               │
   │                                                            │
   │ · Colour is a FLAT LAYER, never shading. Which means a     │
   │   second ink costs nothing creatively.                     │
   │ · Indigo + ochre + cream is a complete palette.            │
   │ · Solid black silhouette shapes beat detailed rendering    │
   │   at small sizes. The pines are unhatched and read         │
   │   instantly from across a table.                           │
   │ · Vast empty space makes the few marks matter more.        │
   │ · Red-orange seals are the only warm accent in the whole   │
   │   image. One accent colour, used sparingly, is enough.     │
   └────────────────────────────────────────────────────────────┘
```

## 2. THE VISUAL THESIS

The mechanic is: **you cannot see your own face.**

So the art states it directly.

```text

   │   EVERY FIGURE ON EVERY CARD IS SEEN FROM BEHIND.        │

   │   veil, or a mask worn on the back of the skull.         │
   │                                                          │
   │   The player holding the card cannot see their own       │
   │   card. Neither can the figure.                          │

## 4. THE EIGHT FIGURES — silhouette first

Each figure must be identifiable at 2.5 inches from across a table. Silhouette does the work; hatching is decoration.

### 16.1 How the ORACLE was finally fixed

```

   ATTEMPT 1   "mask on the back of the head"
               → drew her FACING US, mask on the face.        FAIL

   ATTEMPT 2   same brief, restated harder
               → drew her FACING US, mask on the face.        FAIL

   ┌───────────────────────────────────────────────────────────┐
   │ TWO IDENTICAL FAILURES MEAN THE BRIEF IS WRONG, NOT THE    │
   │ PROMPT. The model has one strong instinct here: a face     │
   │ near a head is a face ON that head. Fighting that instinct │
   │ with more words was never going to work.                   │
   └───────────────────────────────────────────────────────────┘

   ATTEMPT 3   CHANGED THE DESIGN INSTEAD OF THE PROMPT

               1. took the mask OFF her head entirely
               2. put it in her hand, hanging at her hip
               3. attached a reference image (MONK B) purely to
                  anchor the camera angle

               → PASS.

   ┌───────────────────────────────────────────────────────────┐
   │ AND THE REDESIGN IS THE BETTER CARD.                      │
   │                                                           │
   │ "Wears a mask on the back of her head" is a gimmick that    │
   │ only works if you explain it. "Carries a mask she never     │
   │ puts on" is legible in one glance and says more about the   │
   │ Oracle than the original idea did.                        │
   │                                                           │
   │ The blank mask is now the only face in the deck, and it is  │
   │ not attached to anybody. That is the whole game in one      │
   │ object.                                                   │
   └───────────────────────────────────────────────────────────┘

```text

### 16.2 THE LEVER THAT UNBLOCKED IT — a reference for camera angle

```

   Passing a finished card as a REFERENCE IMAGE and saying
   "copy only its viewpoint, ignore its subject" fixed in one
   shot what two rounds of prose could not.

   KEEP THIS FOR ANY FUTURE CARD. Generate one card that gets
   the camera right, then reuse it as the orientation anchor
   for every sibling. It costs nothing and removes the single
   most common failure mode in the set.
